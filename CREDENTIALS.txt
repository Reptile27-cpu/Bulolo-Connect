HOW TO RUN THE PLATFORM AT ANY TIME:
--------------------------------------------------------------------------------
From the root folder:
  npm run dev

Or separately:
  Terminal 1: cd backend && npm run dev
  Terminal 2: cd frontend && npm run dev

Run Automated Backend Test Suite:
  cd backend && npx ts-node src/tests/api.test.ts
